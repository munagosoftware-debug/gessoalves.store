## 🎨 Identidade Visual e UI/UX
- **Cores Principais:** Bege claro/areia (~`#F1E9DC` a `#E8DCC8`) combinado com branco (`#FFFFFF`). *Nota: Alternar entre seções para dar ritmo visual (evitar branco puro isolado em todas as seções).*
- **Cores de Apoio:** Cinza-chumbo/grafite escuro (~`#2B2E38`) e azul-marinho profundo (~`#1B2A5C`) para textos, títulos, botões e ícones. Prata/metálico em degradê (~`#C9CDD3` a `#8A8F98`) para acabamentos 3D em relevo.
- **Logo:** Monograma "GA" (G cinza-chumbo, placa de drywall 3D prata, perna do A em azul-marinho) + Wordmark ("GESSO" grafite, "ALVES" azul-marinho) + Tagline "EMPRESA DE GESSO E DRYWALL". *(Requisito: gerar variação com fundo transparente e isolar o "GA" para favicon).*

- Efeitos 3D imersivos.
- Carrosséis fluidos.
- Foco absoluto na conversão de leads (WhatsApp e formulário de orçamento).

---

## 💻 Tech Stack Recomendada
- **Frontend:** HTML5 / CSS3 / JavaScript moderno (ou framework como Next.js/React se preferido pela arquitetura). Mobile-first e foco em acessibilidade.
- **Animações e 3D:** GSAP + ScrollTrigger para interações. Three.js para o 3D (com fallback otimizado para mobile) e Swiper.js para carrosséis.
- **Backend (Formulários/Galeria):** Backend leve utilizando Node.js/Express, PHP, ou BaaS (como Supabase/Firebase) + Storage de imagens (Cloudinary/S3).
- **Acessibilidade:** Respeitar `prefers-reduced-motion` e garantir alta pontuação no Lighthouse.
